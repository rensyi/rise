# Rise Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Rise, a Material 3 mobile app that logs wake-up times in one tap and colours the calendar days by how close each wake-up was to the user's target.

**Architecture:** One Expo screen with dialogs and no navigation library. All rules live in pure functions in `src/lib/time.ts`; `src/storage.ts` reads and writes three AsyncStorage keys; `src/useRise.ts` holds state and joins the two; components only render props and call callbacks. Wake and bedtime are separate stores, and no function takes both.

**Tech Stack:** Expo SDK 57 (React Native 0.86, React 19, TypeScript 6), `react-native-paper` 5 (Material 3), `react-native-paper-dates` (time picker), `@react-native-async-storage/async-storage` 2, Jest through `jest-expo`.

**Spec:** `docs/superpowers/specs/2026-10-12-rise-design.md`

## Global Constraints

- **No commits by agents.** Never run `git commit`, `git push`, or open a PR. Never add `Co-Authored-By` or any AI attribution to any file or message. The project owner commits at each checkpoint.
- **Local only.** No network calls, no accounts, no analytics.
- **Independence.** Wake and bedtime records are stored and computed separately. No function accepts both record sets. No sleep duration, no combined score.
- **No navigation library.** One screen; Settings and day editing are dialogs.
- **Dependencies** are limited to: `expo`, `react-native-paper`, `react-native-paper-dates`, `@react-native-async-storage/async-storage`, plus the packages those need at runtime: `react-native-safe-area-context`, `@expo/vector-icons`, `expo-font`, `expo-system-ui`. Dev: `jest-expo`, `jest`, `@types/jest`. Install with `npx expo install` so versions match the SDK.
- **Defaults:** `wakeTarget` `06:00`, `bedTarget` `22:00`, `bedEnabled` `false`, `applyTargetsToPast` `false`.
- **Storage keys:** `rise.wake`, `rise.bed`, `rise.config`. Date keys are local `YYYY-MM-DD`. Times and targets are 24-hour `HH:mm`.
- **Levels:** `diff ≤ 0` is 4, `≤ 30` is 3, `≤ 60` is 2, otherwise 1; no entry is 0.
- **Palette:** Lavender `#A996E0`, Lilac haze `#E4DCF7`, Morning mist `#F7F4FD`, Deep plum `#2E2645`, Peach blush `#F4B49A`, Butter sun `#F3D68A`, Muted purple `#6B5FA0`, dark card `#3D3358`.
- **Contrast rules:** text on Lavender, Peach blush and Butter sun is always Deep plum. Peach blush and Butter sun are fills only. Text on cards and dialogs uses `onSurface`, never `onSurfaceVariant`. Text buttons set `textColor={theme.colors.onSurface}`.
- **Tile opacities:** level 4 `1.0`, level 3 `0.55`, level 2 `0.35`, level 1 `0.18`.
- **Copy:** `I'm up`, `In bed`, `Logged <time>`, `Couldn't save. Try again.`, `Couldn't load your data.`, `Try again`, `Apply targets to past days`, `Track bedtime`, `Target wake-up time`, `Target bedtime`.
- **`month` is 0-based** everywhere, as in JavaScript's `Date`.
- **`docs/prototype/rise-tracker.jsx` is a reference prototype.** Do not edit, import or delete it. (It was moved there from the repo root after implementation, at the owner's request.)

## Review Focus

Conditions the spec implies but does not spell out, most likely first. Each is pinned by a test or check in the task named.

1. **The app is left open overnight.** Tapping "I'm up" the next morning must log under the new date, and today's outline and the FAB must update when the app returns to the foreground. Pinned in Task 2 (`logDateFor` takes `now`) and Task 6 (clock read at tap time, `AppState` refresh, manual check).
2. **The device is ahead of UTC.** A 06:30 wake-up in UTC+8 must be filed under the local date, not UTC's previous day. Pinned in Task 2 (`use the local date and time, not UTC`, run in a fixed zone).
3. **Stored data has the wrong shape.** The prototype's plain-string format, a hand-edited value, or an invalid time must be dropped entry by entry without crashing or producing a colourless tile. Pinned in Task 3 (`parseRecords`, `parseConfig`).
4. **The FAB is tapped twice, or tapped after the day is already logged.** The first entry and its stored target must survive. Pinned in Task 2 (`addEntry`).
5. **Storage cannot be read at launch.** The app must not open empty and then save over real data. Pinned in Task 3 (`load` rejects) and Task 6 (retry screen).

```ts
export type Mode = 'wake' | 'bed';
export type Entry = { time: string; target: string };
export type Records = Record<string, Entry>;
export type Level = 1 | 2 | 3 | 4;
export type Config = {
  wakeTarget: string;
  bedEnabled: boolean;
  bedTarget: string;
  applyTargetsToPast: boolean;
};
export type MonthStats = { logged: number; onTime: number; avgLate: number | null };

export const DEFAULT_CONFIG: Config = {
  wakeTarget: '06:00',
  bedEnabled: false,
  bedTarget: '22:00',
  applyTargetsToPast: false,
};

const TIME_RE = /^([01]\d|2[0-3]):[0-5]\d$/;
const pad = (n: number) => String(n).padStart(2, '0');

export function isTime(value: unknown): value is string {
  return typeof value === 'string' && TIME_RE.test(value);
}

export function parseTime(time: string): number {
  const [h, m] = time.split(':').map(Number);
  return h * 60 + m;
}

export function dateKey(date: Date): string {
  return `${date.getFullYear()}-${pad(date.getMonth() + 1)}-${pad(date.getDate())}`;
}

export function timeOf(date: Date): string {
  return `${pad(date.getHours())}:${pad(date.getMinutes())}`;
}

// A bedtime logged before noon belongs to the night before.
export function bedDateFor(now: Date): string {
  const date = new Date(now);
  if (date.getHours() < 12) date.setDate(date.getDate() - 1);
  return dateKey(date);
}

export function logDateFor(mode: Mode, now: Date): string {
  return mode === 'bed' ? bedDateFor(now) : dateKey(now);
}

// Bedtimes cross midnight, so bed mode compares on a noon-to-noon clock.
export function diffMinutes(target: string, logged: string, mode: Mode): number {
  const place = (min: number) => (mode === 'bed' && min < 720 ? min + 1440 : min);
  return place(parseTime(logged)) - place(parseTime(target));
}

export function level(target: string, logged: string, mode: Mode): Level {
  const diff = diffMinutes(target, logged, mode);
  if (diff <= 0) return 4;
  if (diff <= 30) return 3;
  if (diff <= 60) return 2;
  return 1;
}

export function latenessLabel(diff: number): string {
  if (diff === 0) return 'On time';
  if (diff < 0) return `${-diff}m early`;
  if (diff < 120) return `${diff}m late`;
  return `${Math.round(diff / 6) / 10}h late`;
}

export function effectiveTarget(entry: Entry, currentTarget: string, applyToPast: boolean): string {
  return applyToPast ? currentTarget : entry.target;
}

// month is 0-based, as in Date.
export function monthStats(
  records: Records,
  year: number,
  month: number,
  mode: Mode,
  currentTarget: string,
  applyToPast: boolean,
): MonthStats {
  const prefix = `${year}-${pad(month + 1)}-`;
  const diffs = Object.keys(records)
    .filter((key) => key.startsWith(prefix))
    .map((key) =>
      diffMinutes(effectiveTarget(records[key], currentTarget, applyToPast), records[key].time, mode),
    );
  if (diffs.length === 0) return { logged: 0, onTime: 0, avgLate: null };
  const late = diffs.reduce((sum, diff) => sum + Math.max(0, diff), 0);
  return {
    logged: diffs.length,
    onTime: diffs.filter((diff) => diff <= 0).length,
    avgLate: Math.round(late / diffs.length),
  };
}

export function shiftMonth(year: number, month: number, delta: number): { year: number; month: number } {
  const date = new Date(year, month + delta, 1);
  return { year: date.getFullYear(), month: date.getMonth() };
}

// Leading nulls pad the first week so day 1 lands under its weekday (Sunday first).
export function monthCells(year: number, month: number): (number | null)[] {
  const blanks = new Date(year, month, 1).getDay();
  const days = new Date(year, month + 1, 0).getDate();
  return [...Array<null>(blanks).fill(null), ...Array.from({ length: days }, (_, i) => i + 1)];
}

// One-tap logging: never overwrites a day that already has an entry.
export function addEntry(records: Records, key: string, time: string, currentTarget: string): Records {
  if (records[key]) return records;
  return { ...records, [key]: { time, target: currentTarget } };
}

// Day dialog: a new entry stores the current target, an edit keeps the stored one.
export function upsertEntry(records: Records, key: string, time: string, currentTarget: string): Records {
  return { ...records, [key]: { time, target: records[key]?.target ?? currentTarget } };
}

export function removeEntry(records: Records, key: string): Records {
  const { [key]: _removed, ...rest } = records;
  return rest;
}

export function formatTime(time: string, locale?: string): string {
  const [h, m] = time.split(':').map(Number);
  return new Intl.DateTimeFormat(locale, { hour: 'numeric', minute: '2-digit' }).format(
    new Date(2000, 0, 1, h, m),
  );
}

export function uses24Hour(locale?: string): boolean {
  return !new Intl.DateTimeFormat(locale, { hour: 'numeric' }).resolvedOptions().hour12;
}
```

```ts
import AsyncStorage from '@react-native-async-storage/async-storage';
import { type Config, DEFAULT_CONFIG, type Records, isTime } from './lib/time';

const KEYS = { wake: 'rise.wake', bed: 'rise.bed', config: 'rise.config' } as const;
const DATE_RE = /^\d{4}-\d{2}-\d{2}$/;

const isObject = (value: unknown): value is Record<string, unknown> =>
  typeof value === 'object' && value !== null && !Array.isArray(value);

function parseJson(raw: string | null): unknown {
  if (raw === null) return null;
  try {
    return JSON.parse(raw);
  } catch {
    return null;
  }
}

// Unreadable or wrongly shaped data is dropped entry by entry; valid entries are kept.
export function parseRecords(raw: string | null): Records {
  const data = parseJson(raw);
  if (!isObject(data)) return {};
  const records: Records = {};
  for (const [key, value] of Object.entries(data)) {
    if (DATE_RE.test(key) && isObject(value) && isTime(value.time) && isTime(value.target)) {
      records[key] = { time: value.time, target: value.target };
    }
  }
  return records;
}

export function parseConfig(raw: string | null): Config {
  const data = parseJson(raw);
  if (!isObject(data)) return DEFAULT_CONFIG;
  return {
    wakeTarget: isTime(data.wakeTarget) ? data.wakeTarget : DEFAULT_CONFIG.wakeTarget,
    bedEnabled: typeof data.bedEnabled === 'boolean' ? data.bedEnabled : DEFAULT_CONFIG.bedEnabled,
    bedTarget: isTime(data.bedTarget) ? data.bedTarget : DEFAULT_CONFIG.bedTarget,
    applyTargetsToPast:
      typeof data.applyTargetsToPast === 'boolean'
        ? data.applyTargetsToPast
        : DEFAULT_CONFIG.applyTargetsToPast,
  };
}

// Rejects if a read fails, so the app never saves over data it could not read.
export async function load(): Promise<{ wake: Records; bed: Records; config: Config }> {
  const [wake, bed, config] = await Promise.all([
    AsyncStorage.getItem(KEYS.wake),
    AsyncStorage.getItem(KEYS.bed),
    AsyncStorage.getItem(KEYS.config),
  ]);
  return { wake: parseRecords(wake), bed: parseRecords(bed), config: parseConfig(config) };
}

export const saveWake = (records: Records) => AsyncStorage.setItem(KEYS.wake, JSON.stringify(records));
export const saveBed = (records: Records) => AsyncStorage.setItem(KEYS.bed, JSON.stringify(records));
export const saveConfig = (config: Config) => AsyncStorage.setItem(KEYS.config, JSON.stringify(config));

// Shows `next` at once, then reverts to `prev` if the save fails.
export async function persist<T>(
  prev: T,
  next: T,
  set: (value: T) => void,
  save: (value: T) => Promise<void>,
): Promise<boolean> {
  set(next);
  try {
    await save(next);
    return true;
  } catch {
    set(prev);
    return false;
  }
}
```

```ts
import { useCallback, useEffect, useState } from 'react';
import {
  type Config,
  DEFAULT_CONFIG,
  type Mode,
  type Records,
  addEntry,
  formatTime,
  logDateFor,
  removeEntry,
  timeOf,
  upsertEntry,
} from './lib/time';
import { load, persist, saveBed, saveConfig, saveWake } from './storage';

const SAVE_FAILED = "Couldn't save. Try again.";

export function useRise() {
  const [status, setStatus] = useState<'loading' | 'ready' | 'failed'>('loading');
  const [wake, setWake] = useState<Records>({});
  const [bed, setBed] = useState<Records>({});
  const [config, setConfigState] = useState<Config>(DEFAULT_CONFIG);
  const [message, setMessage] = useState<string | null>(null);

  const reload = useCallback(() => {
    setStatus('loading');
    load().then(
      (data) => {
        setWake(data.wake);
        setBed(data.bed);
        setConfigState(data.config);
        setStatus('ready');
      },
      () => setStatus('failed'),
    );
  }, []);

  useEffect(() => {
    reload();
  }, [reload]);

  // Wake and bedtime are separate stores; each write touches exactly one.
  const write = async (mode: Mode, next: Records, done: string | null) => {
    const saved =
      mode === 'wake'
        ? await persist(wake, next, setWake, saveWake)
        : await persist(bed, next, setBed, saveBed);
    setMessage(saved ? done : SAVE_FAILED);
  };

  const recordsOf = (mode: Mode) => (mode === 'wake' ? wake : bed);
  const targetOf = (mode: Mode) => (mode === 'wake' ? config.wakeTarget : config.bedTarget);

  // Reads the clock at tap time, so an app left open overnight logs under the right day.
  const logNow = async (mode: Mode) => {
    const now = new Date();
    const records = recordsOf(mode);
    const next = addEntry(records, logDateFor(mode, now), timeOf(now), targetOf(mode));
    if (next !== records) await write(mode, next, `Logged ${formatTime(timeOf(now))}`);
  };

  const setEntry = (mode: Mode, key: string, time: string) =>
    write(mode, upsertEntry(recordsOf(mode), key, time, targetOf(mode)), null);

  const deleteEntry = (mode: Mode, key: string) =>
    write(mode, removeEntry(recordsOf(mode), key), null);

  const setConfig = async (next: Config) => {
    if (!(await persist(config, next, setConfigState, saveConfig))) setMessage(SAVE_FAILED);
  };

  return {
    status,
    reload,
    wake,
    bed,
    config,
    message,
    clearMessage: () => setMessage(null),
    logNow,
    setEntry,
    deleteEntry,
    setConfig,
  };
}
```

import { useState } from 'react';
import { StyleSheet, View } from 'react-native';
import { Button, Dialog, type MD3Theme, Portal, Text, useTheme } from 'react-native-paper';
import {
  type Entry,
  type Mode,
  diffMinutes,
  effectiveTarget,
  formatTime,
  latenessLabel,
  level,
} from '../lib/time';
import { tileColor, tileTextColor } from '../theme';
import TimeField from './TimeField';

type Props = {
  dateKey: string;
  mode: Mode;
  entry: Entry | undefined;
  currentTarget: string;
  applyToPast: boolean;
  onSave: (time: string) => void;
  onDelete: () => void;
  onDismiss: () => void;
};

// Mount with key={dateKey} so the time field starts fresh for each day.
export default function DayDialog({
  dateKey,
  mode,
  entry,
  currentTarget,
  applyToPast,
  onSave,
  onDelete,
  onDismiss,
}: Props) {
  const theme = useTheme<MD3Theme>();
  const [time, setTime] = useState(entry?.time ?? currentTarget);
  const target = entry ? effectiveTarget(entry, currentTarget, applyToPast) : currentTarget;
  const tileLevel = level(target, time, mode);
  const name = mode === 'wake' ? 'Wake-up' : 'Bedtime';
  const [year, month, day] = dateKey.split('-').map(Number);
  const date = new Date(year, month - 1, day).toLocaleDateString(undefined, {
    weekday: 'long',
    day: 'numeric',
    month: 'long',
  });

  return (
    <Portal>
      <Dialog visible onDismiss={onDismiss}>
        <Dialog.Title>{name}</Dialog.Title>
        <Dialog.Content style={styles.content}>
          <Text variant="bodyLarge">{date}</Text>
          <Text variant="bodyMedium">Target {formatTime(target)}</Text>
          <TimeField label={`${name} time`} value={time} onChange={setTime} />
          {/* The preview sits on the screen background so it matches the calendar tile. */}
          <View style={[styles.preview, { backgroundColor: theme.colors.background }]}>
            <View style={[styles.previewFill, { backgroundColor: tileColor(tileLevel) }]}>
              <Text variant="labelLarge" style={{ color: tileTextColor(tileLevel, theme) }}>
                {latenessLabel(diffMinutes(target, time, mode))}
              </Text>
            </View>
          </View>
        </Dialog.Content>
        <Dialog.Actions>
          {entry && (
            <Button textColor={theme.colors.onSurface} onPress={onDelete}>
              Delete
            </Button>
          )}
          <Button textColor={theme.colors.onSurface} onPress={onDismiss}>
            Cancel
          </Button>
          <Button mode="contained" onPress={() => onSave(time)}>
            Save
          </Button>
        </Dialog.Actions>
      </Dialog>
    </Portal>
  );
}

const styles = StyleSheet.create({
  content: { gap: 12 },
  preview: { borderRadius: 8, overflow: 'hidden' },
  previewFill: { alignItems: 'center', paddingVertical: 10 },
});

```tsx
import { useEffect, useState } from 'react';
import { AppState, ScrollView, StyleSheet, View } from 'react-native';
import {
  ActivityIndicator,
  Appbar,
  Button,
  Chip,
  FAB,
  type MD3Theme,
  SegmentedButtons,
  Snackbar,
  Text,
  useTheme,
} from 'react-native-paper';
import { useSafeAreaInsets } from 'react-native-safe-area-context';
import DayDialog from './components/DayDialog';
import MonthCalendar, { Legend } from './components/MonthCalendar';
import SettingsDialog from './components/SettingsDialog';
import StatsRow from './components/StatsRow';
import { type Mode, dateKey, formatTime, logDateFor, monthStats, shiftMonth } from './lib/time';
import { palette } from './theme';
import { useRise } from './useRise';

export default function HomeScreen() {
  const theme = useTheme<MD3Theme>();
  const insets = useSafeAreaInsets();
  const rise = useRise();
  const [now, setNow] = useState(() => new Date());
  const [picked, setPicked] = useState<Mode>('wake');
  const [view, setView] = useState(() => ({ year: now.getFullYear(), month: now.getMonth() }));
  const [selectedKey, setSelectedKey] = useState<string | null>(null);
  const [settingsOpen, setSettingsOpen] = useState(false);

  // The app is often left open overnight: refresh "today" when it returns to the foreground.
  useEffect(() => {
    const subscription = AppState.addEventListener('change', (state) => {
      if (state === 'active') setNow(new Date());
    });
    return () => subscription.remove();
  }, []);

  const screen = [styles.screen, { backgroundColor: theme.colors.background }];

  if (rise.status === 'loading') {
    return (
      <View style={[screen, styles.centered]}>
        <ActivityIndicator />
      </View>
    );
  }

  // Shown instead of an empty app, so a later save cannot overwrite data that failed to load.
  if (rise.status === 'failed') {
    return (
      <View style={[screen, styles.centered]}>
        <Text variant="bodyLarge">Couldn't load your data.</Text>
        <Button mode="contained" onPress={rise.reload}>
          Try again
        </Button>
      </View>
    );
  }

  // With bedtime tracking off there is only Wake mode.
  const mode: Mode = rise.config.bedEnabled ? picked : 'wake';
  const records = mode === 'wake' ? rise.wake : rise.bed;
  const target = mode === 'wake' ? rise.config.wakeTarget : rise.config.bedTarget;
  const applyToPast = rise.config.applyTargetsToPast;
  const canLog = !records[logDateFor(mode, now)];

  return (
    <View style={screen}>
      <Appbar.Header>
        <Appbar.Content title="Rise" />
        <Appbar.Action icon="cog" accessibilityLabel="Settings" onPress={() => setSettingsOpen(true)} />
      </Appbar.Header>

      <ScrollView contentContainerStyle={styles.content}>
        {rise.config.bedEnabled && (
          <SegmentedButtons
            value={mode}
            onValueChange={(value) => setPicked(value as Mode)}
            buttons={[
              { value: 'wake', label: 'Wake', icon: 'white-balance-sunny' },
              { value: 'bed', label: 'Bedtime', icon: 'bed' },
            ]}
          />
        )}
        {/* Peach blush is a fill only: text on it is always deep plum. */}
        <Chip style={styles.chip} textStyle={{ color: palette.deepPlum }}>
          {`Target ${mode === 'wake' ? 'wake-up' : 'bedtime'} ${formatTime(target)}`}
        </Chip>
        <StatsRow stats={monthStats(records, view.year, view.month, mode, target, applyToPast)} />
        <MonthCalendar
          year={view.year}
          month={view.month}
          records={records}
          mode={mode}
          currentTarget={target}
          applyToPast={applyToPast}
          todayKey={dateKey(now)}
          onPrev={() => setView(shiftMonth(view.year, view.month, -1))}
          onNext={() => setView(shiftMonth(view.year, view.month, 1))}
          onSelectDay={setSelectedKey}
        />
        <Legend />
      </ScrollView>

      {canLog && (
        <FAB
          icon={mode === 'wake' ? 'white-balance-sunny' : 'bed'}
          label={mode === 'wake' ? "I'm up" : 'In bed'}
          style={[styles.fab, { bottom: 16 + insets.bottom }]}
          onPress={() => {
            setNow(new Date());
            rise.logNow(mode);
          }}
        />
      )}

      {selectedKey && (
        <DayDialog
          key={selectedKey}
          dateKey={selectedKey}
          mode={mode}
          entry={records[selectedKey]}
          currentTarget={target}
          applyToPast={applyToPast}
          onSave={(time) => {
            rise.setEntry(mode, selectedKey, time);
            setSelectedKey(null);
          }}
          onDelete={() => {
            rise.deleteEntry(mode, selectedKey);
            setSelectedKey(null);
          }}
          onDismiss={() => setSelectedKey(null)}
        />
      )}

      <SettingsDialog
        visible={settingsOpen}
        config={rise.config}
        onChange={rise.setConfig}
        onDismiss={() => setSettingsOpen(false)}
      />

      <Snackbar visible={rise.message !== null} onDismiss={rise.clearMessage} duration={3000}>
        {rise.message ?? ''}
      </Snackbar>
    </View>
  );
}

const styles = StyleSheet.create({
  screen: { flex: 1 },
  centered: { alignItems: 'center', justifyContent: 'center', gap: 16 },
  content: { padding: 16, paddingBottom: 96, gap: 16 },
  chip: { alignSelf: 'center', backgroundColor: palette.peachBlush },
  fab: { position: 'absolute', right: 16 },
});
```
